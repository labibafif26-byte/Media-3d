# Folder Audio Efek Suara (.mp3)

Letakkan file-file efek suara berikut di folder ini jika ingin menggunakan rekaman suara spesifik:
1. `angin.mp3` - Suara desau angin dan suasana alam normal.
2. `gemuruh.mp3` - Suara gemuruh tremor seismik vulkanik (tahap aktivitas meningkat).
3. `erupsi.mp3` - Suara ledakan dentuman dan gemuruh erupsi dahsyat.

*Catatan: Sistem simulasi ini juga memiliki Web Audio API Synthesizer bawaan (Procedural Audio Engine) yang menghasilkan gelombang suara angin, getaran frekuensi rendah gempa vulkanik, dan ledakan erupsi secara dinamis tanpa perlu file eksternal.*

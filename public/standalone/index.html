🌋 Kawah (Crater)

Bagian terbuka di puncak gunung tempat material vulkanik seperti gas magma, piroklastik, abu, dan lava pijar dapat keluar. Klik indikator di sebelah kiri atau klik langsung pin 3D di gunung untuk membedah bagian lainnya.

Simulasi Parameter: Pengawasan visual 24 jam dengan thermal imaging dan gas sniffing drone.
Peringatan Edukasi: Visualisasi ini dibuat untuk tujuan pembelajaran akademis. Status aktivitas gunung api nyata ditentukan berdasarkan pemantauan dan analisis data oleh lembaga/otoritas terkait (seperti PVMBG/ESDM). Perilaku hewan atau satu gejala lingkungan saja tidak dapat dijadikan dasar tunggal untuk memprediksi erupsi.

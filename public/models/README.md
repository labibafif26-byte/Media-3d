# Folder Model 3D (.glb / .gltf)

Letakkan file-file 3D GLB di folder ini jika Anda memiliki model kustom:
1. `gunung-api.glb` - Model utama gunung berapi (bisa berupa model utuh atau cutaway penampang).
2. `pohon.glb` - Model pohon/vegetasi.
3. `rusa.glb` - Model satwa rusa.
4. `burung.glb` - Model burung terbang.
5. `hewan-kecil.glb` - Model kelinci atau satwa tanah kecil.

*Catatan: Sistem simulasi ini dilengkapi dengan generator model 3D prosedural tingkat tinggi yang otomatis aktif jika file .glb belum dimasukkan, sehingga simulasi langsung berjalan dengan visual penampang 3D lengkap, animasi hewan, burung, pohon, lava, dan partikel erupsi tanpa error.*
